ABOUT PINGMAP

A simple public IP directory.

PingMap is designed as a searchable catalog of public IP addresses, organized by geography and network information. Location data comes from IP2Location.io, while reachability checks use Globalping.

01Searchable

Find entries quickly with IP, city, country, ISP, or ASN.

02Automatic geolocation

Submitted addresses are enriched with country, region, city, coordinates, ASN, and network information.

03Community-built

Contributors grow the shared directory with public, reachable IPs.
